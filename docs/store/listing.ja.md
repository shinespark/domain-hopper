# Chrome ウェブストア掲載文（日本語）

## 短い説明

今のページを、パスはそのままで別の環境に切り替えます。

## 詳しい説明

domain-hopper は、開いているタブを同じサイトの別の環境（本番・ステージング・ローカルなど）に切り替える拡張機能です。パス・クエリ・ハッシュはそのまま引き継ぎます。

- 今のページをプロジェクトとして登録するか、既存のプロジェクトに別の環境として追加できます。
- 環境をクリックすると、今のタブがその環境に切り替わります。
- Cmd/Ctrl を押しながらクリック、または中クリックで、今のタブの右隣にバックグラウンドのタブとして開きます。
- 設定ページで、環境の追加、スキームやホストの変更、プロジェクトと環境の名前変更・並べ替え・削除ができます。
- localhost やポート付きのアドレスを含む、http と https のページで使えます。

通信は一切行わず、解析ツールも入っていません。登録内容は chrome.storage.sync に保存され、Chrome の同期をオンにしている場合は自分の Chrome 同士で引き継げます（オフの場合はこの端末内にだけ保存されます）。

## 権限を使う理由

- activeTab: ツールバーのボタンを押したときだけ今のタブの URL を読み、どのサイトを開いているかと切り替え先を判断するために使います。
- storage: 登録したプロジェクトと環境を保存し、Chrome の同期をオンにしている場合に自分の Chrome 同士で同期するために使います。

## データの扱い

- 個人情報を収集せず、開発者を含め外部のサーバーには何も送信しません。
- 読み取るのは、ボタンを押した時点での今のタブの URL だけです。
- 登録した origin・ラベル・プロジェクト名は chrome.storage.sync に保存されます。Chrome の同期をオンにしている場合のみ、Chrome によって利用者の Google アカウントに同期され、オフの場合はこの端末内にだけ保存されます。
